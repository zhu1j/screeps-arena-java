# 版本迭代

这个目录记录 Screeps Arena Java 绑定库的版本计划，以及还没做、但以后可能值得做的想法。

## 目录约定

```
iterations/
  README.md            本文件：迭代节奏与路线图
  ideas/               迭代想法（还没排期的建议，每条一个文档）
    NNN-简短标题.md
  v0.1/                某个版本完成后的结果记录
  v0.2/
```

- `ideas/` 是**想法池**，不是待办清单。写进去不代表一定要做，只是别忘了。
- 每条想法用三位编号 + 短横线 + 英文小写标题，例如 `001-idiomatic-java-api.md`。
- 一条想法被真正排期时，把它从 `ideas/` 挪进对应版本的说明里，并在文档头部标注状态。

## 已定下的长期决定

这些是已经拍过板、不需要再讨论的前提：

- **编译路线**：TeaVM 0.15.0 的 JS 后端，输出 ES2015 模块。不用 GWT / JSweet / JVM-in-JS。
- **对局里没有 JVM**。Java 只存在于构建阶段，产物是一个纯 JS 文件。
- **跨 tick 状态用静态字段**为主，同时保留给游戏对象挂自定义属性的能力。
- **构建**：单模块 Maven，`mvn package` 直接产出 `dist/<关卡>/main.mjs`。
- **一个关卡一个产物目录**。`/arena` 根模块导出什么取决于当前关卡，静态 import 一个
  不存在的符号会让整个 ESM 加载失败，所以按关卡分编译单元，而不是在运行时分支。
