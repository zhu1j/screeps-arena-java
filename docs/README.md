# 文档索引

建议按顺序读：

| 文档 | 讲什么 | 适合谁 |
| --- | --- | --- |
| [01 项目概览](01-项目概览.md) | 为什么要做、设计原则、v0.1 能做什么 | 第一次接触这个项目的人 |
| [02 架构总览](02-架构总览.md) | 分层架构、编译管线、一关一产物、一次 tick 的生命周期 | 想看全貌的人 |

| [04 离线模拟器与回归](04-离线模拟器与回归.md) | mock 模拟器怎么搭、回归套件怎么跑、怎么加场景 | 写策略、想快速迭代的人 |
| [05 构建与使用](05-构建与使用.md) | 环境、构建、watch、在自己的 IntelliJ 工程里用、排错 | 准备上手写 bot 的人 |
